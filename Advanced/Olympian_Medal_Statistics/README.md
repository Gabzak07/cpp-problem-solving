# Olympian_Medal_Statistics

Analyzes historical Olympic data from a CSV dataset to track athletes' achievements, calculating yearly medal counts, overall averages, and identifying the most decorated athletes.

Input: `U1.csv` — dataset containing medal types, athlete names, Olympic years, host cities, and sports events.  
Output: `U1rez.txt` — a chronologically sorted list of medalists, aggregated medal counts per year (with gold/silver/bronze breakdown), the average number of medals per Olympics, and a list of the top-performing athletes.
