# Programming_Competition_Scoring

Calculates and ranks the results of a programming competition based on the number of correctly solved tasks and the total time spent on them.

Input: `U2.txt` — number of participants, total tasks offered, and each participant's submission log (start time, end time, and whether the solution was correct).  
Output: `U2rez.txt` — the highest number of correctly solved tasks, followed by a sorted leaderboard of successful participants, showing their success percentage and total time spent on correct submissions.
