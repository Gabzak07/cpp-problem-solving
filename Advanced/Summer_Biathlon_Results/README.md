# Summer_Biathlon_Results

Computes total race time (finish–start + shooting penalties) and outputs sorted lists for girls and boys.

Input: `Duomenys.txt` — starters (name, id, start time) and finishers (id, finish time, shooting hits)  
Output: `Rezultatas.txt` — sections `Merginos` and `Vaikinai`: `id name h m s` sorted by total time
