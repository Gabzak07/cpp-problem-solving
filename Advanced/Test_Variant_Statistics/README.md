# Test_Variant_Statistics

Analyzes student test results grouped by test variant to calculate pass rates (scores >= 15) and identify the highest score achieved for each variant.

Input: `U1.txt` — the total number of students, followed by their assigned test variant and scores for 10 individual tasks.  
Output: `U1rez.txt` — an unsorted and sorted summary of each variant, displaying the student count, pass percentage, and maximum score.
