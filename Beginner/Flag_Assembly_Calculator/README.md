# Flag_Assembly_Calculator

Calculates the maximum number of flags that can be assembled using provided quantities of colored strips, and determines the leftover count for each color. Each flag requires exactly two strips of yellow, green, and red.

Input: `Duomenys.txt` — the number of color batches, followed by the color code ('G', 'Z', or 'R') and the quantity of strips in that batch.  
Output: `Rezultatas.txt` — the total number of fully assembled flags, followed by the remaining unused strips for each color.
