# Ski_Gear_Price_Filter

Selects ski-and-boot gear bundles whose total price falls within a specified budget range,
then outputs the cheapest, most expensive, count, and all valid bundle prices.

Input: Duomenys.txt — minimum and maximum budget, number of bundles, and prices of skis and boots  
Output: Rezultatas.txt — min and max valid bundle prices, count of valid bundles, and their prices
