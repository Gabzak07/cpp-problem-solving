# Student_Height_Statistics

Calculates the average height of a class, separated by gender, and determines if a basketball team can be formed for each gender based on a minimum height requirement.

Input: `Duomenys.txt` — total number of students and their heights (positive values represent girls, negative values represent boys).  
Output: `Rezultatas.txt` — overall average height, gender-specific averages, and confirmation messages on whether a valid basketball team can be formed for each gender.
