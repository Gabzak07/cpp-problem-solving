# TaskSumCalculator

Reads daily task counts from a file and calculates how many tasks each participant solved in total, then outputs the grand total.

**Input:**  
`duomenys.txt`  
- First line: number of participants  
- Next lines: number of days and daily task counts per participant  

**Output:**  
`rezultatai.txt`  
- Each participant's total tasks solved  
- Final line: total tasks solved by everyone
