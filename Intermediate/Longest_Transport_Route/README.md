# Longest_Transport_Route

Identifies the public transport route that services the highest number of stations and lists all the stops along that route.

Input: `Duomenys.txt` — total number of stations, followed by each station's name, the number of routes stopping there, and their respective route IDs.  
Output: `Rezultatas.txt` — the ID of the route with the most stops and the names of all the stations it services.
