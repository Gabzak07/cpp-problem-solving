# Magic_Cards_Score_Manager

Processes board game turns to aggregate each player's positive points, identifies players with the highest and lowest scores, and modifies the scoreboard using specific insertion rules.

Input: `Duomenys.txt` — total number of turns, followed by the player ID and points earned for each turn.  
Output: `Rezultatas.txt` — aggregated positive scores per player, lists of players with minimum and maximum scores, and the final scoreboard after specific array insertions.
