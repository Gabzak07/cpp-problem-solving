# Ordered_Array_Insertion

Merges a secondary list of unordered integers into an already sorted sequence, inserting each element at its correct position to maintain the ascending order without creating a new array.

Input: `Duomenys.txt` — the size and elements of the initial sorted sequence, followed by the size and elements of the list to be inserted.  
Output: `Rezultatas.txt` — the final combined and sorted sequence, printed one element per line.
