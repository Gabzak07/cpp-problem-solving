# Robot_Grid_Navigation

Simulates a robot navigating a 2D grid based on a sequence of directional commands, actively avoiding predefined obstacles along its path.

Input: `Duomenys.txt` — the number of obstacles, their respective (X, Y) coordinates, and a sequence of movement instructions (direction and number of steps).  
Output: `Rezultatas.txt` — the final (X, Y) coordinates of the robot after executing all valid moves.
