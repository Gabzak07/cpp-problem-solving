# Student_Answer_Comparison

Compares the test answers of a group of students against a specific target student to determine how many answers match. 

Input: `Duomenys.txt` — number of students, test length, target student index, and a list of students with their respective test answers.  
Output: `Rezultatas.txt` — the target student's name, followed by a list of the other students sorted by the number of matching answers.
